## 图片工作流（重要，照此操作不会乱）

1. `scripts/fetch-art.sh` 已停用，不再允许候选图直接进入正式目录。
2. `node scripts/fetch-missing.mjs` 只下载临时候选与来源 sidecar；标题护栏只负责初筛。
3. 人工核对题名、艺术家、年份、具体版本、构图、馆藏和许可，再转为 WebP。
4. 在 `artworkImageMeta.ts` 写入具体文件页、provider ID、许可、署名、日期与 SHA-256；在 `artworks.ts` 的 `reference` 记录作品身份/馆藏依据。
5. 运行 `npm run verify:art` 和 `npm run build`；发布前运行严格的 `npm run verify:content`。
6. 自动校验只能证明文件与登记信息一致，不能替代作品身份和许可的人工判断。
